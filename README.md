# 🚀 RAG AI Chatbot

A **Retrieval-Augmented Generation (RAG)** chatbot powered by LlamaIndex and OpenAI/Mistral. Indexes your documents (PDFs, websites) and answers questions with sourced citations. Includes a FastAPI backend + React frontend.


## 🌟 Features
- **Document Intelligence**: Ingests PDFs, TXT, or web pages.
- **AI-Powered Q&A**: Answers questions with context from your docs.
- **Full-Stack Ready**: FastAPI backend + React frontend.
- **Citations**: Shows sources for generated answers.


## 🛠️ Tech Stack
| Component       | Technology               |
|-----------------|--------------------------|
| **Backend**     | FastAPI, LlamaIndex      |
| **LLM**         | OpenAI GPT-3.5/Mistral   |
| **Frontend**    | React, Tailwind CSS      |
| **Vector DB**   | (Optional) Pinecone/FAISS|


## 🚀 Quick Start

### Prerequisites
